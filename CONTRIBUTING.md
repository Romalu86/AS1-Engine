# Contributing

Keep changes focused on correctness, maintainability and compatibility with the original game behavior.

- Do not add generated build artifacts to the repository.
- Do not remove or alter third-party license notices.
- Do not apply the project source license to Sigma-Team game content.
- Keep runtime resources separate from source changes when reviewing patches.
- Prefer clear semantic names and concise technical comments.
- Avoid comments that describe temporary process history, internal audit stages or recovery workflow.
